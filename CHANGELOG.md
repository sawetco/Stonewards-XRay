# Changelog

## 1.0.0

Initial public release.

- Client-side highlighting for chests and discoverable objects.
- Optional terrain X-Ray mode.
- Three target modes: Chests, Chests + Discoverables, and All.
- Adjustable reveal distance from 15m to unlimited.
- Adjustable target opacity from 25% to 100%.
- Optional target name tags and distance labels.
- In-game overlay with current mod settings.
- Event-driven target scanning to avoid periodic frame hitches.
- Multiplayer-compatible client-side visual behavior.
- Automatic BepInEx installation and local plugin compilation.
